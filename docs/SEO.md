# SEO

The site is **fully prerendered**: every public URL ships as real HTML with
its content, metadata and structured data baked in at build time. Crawlers
don't need JavaScript for the content itself.

## What each route ships

`src/site/seo.ts` defines per-route metadata (title, description, OG image)
and JSON-LD. For every tool page that includes:

- **`<title>` / meta description** aimed at the tool's search query, with
  the privacy hook ("no upload / in your browser").
- **Open Graph + Twitter cards** (`og.png`, generated by `scripts/og-image.mjs`).
- **JSON-LD**: `SoftwareApplication` (name, category, URL, "Browser"
  operating system, free price specification) and a `FAQPage` block answering
  the privacy/privacy-adjacent questions people ask about these tools
  ("Does it upload my file?", "Is it free?", …).
- Canonical URL + `robots` meta.

Titles are rendered server-side during prerendering (via `@solidjs/meta`),
so they appear in the static HTML — not just after hydration.

## Build artifacts

`scripts/postbuild.mjs` (runs after `vite build`) adds:

- `dist/sitemap.xml` — one entry per public route (absolute URLs from
  `VITE_SITE_URL`).
- `dist/robots.txt` — allows everything, points to the sitemap.
- `dist/404.html` — branded not-found page for unknown URLs.
- `dist/og.png` — from `scripts/og-image.mjs` (plain-canvas PNG, no deps).

## Static-hosting specifics

- **GitHub Pages serves `404.html`** for unknown paths automatically (the
  Pages "custom 404" behavior), which matches the generated file.
- `og:url` / `og:image` use `VITE_SITE_URL` when set (CI sets it to the
  live `https://swd543.github.io/pdf` URL); locally they default to
  `http://localhost:3000`.
- The strict CSP includes `script-src 'self' 'nonce-…'` (fixed build-time
  nonce — see [Architecture](ARCHITECTURE.md)); crawlers that execute JS
  will find the site behaving normally, and non-JS crawlers get the full
  prerendered content anyway.

## No analytics

There is deliberately no analytics at launch (privacy is the product pitch).
If analytics is added later it must stay consent-free-of-data: no user-level
tracking, nothing that contradicts the "your files never leave your device"
promise.
